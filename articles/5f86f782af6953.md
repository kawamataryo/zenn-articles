Raycast の AI API を使ってちょっと便利なAI拡張機能を作ってみたので紹介です。

## Raycast AI APIとは？

Raycast AI APIは、Raycastの拡張機能開発者が、手軽にLLMを利用するためのAPIです。Raycast Proユーザーであれば、APIキーや追加の依存を必要とせず、シームレスにAIモデルを利用できます。

https://developers.raycast.com/api-reference/ai

使い方は主に2つで、`AI.ask` と `useAI` です。

`AI.ask` はpromptと設定を与えるとそれにそった内容の文字列を非同期で返します。

```ts
const result = await AI.ask("こんにちは", {
  model: "gpt-4o-mini",
});
```

`useAI` はReactのフックで、`AI.ask` をラップしたものです。

```tsx
import { useAI } from "@raycast/api";

const result = useAI("こんにちは", {
  model: "gpt-4o-mini",
});
```

`useAI` の方が、streaming response の実装が楽（ `streaming: true` を設定するだけ）なので、もしstreaming response を返すような拡張機能を作る場合は `useAI` を使うと良いです。

:::message
`AI.ask` でもstreaming response ぽい表示は可能です。ただ返却されたデータを`on`で監視し、そのデータを元に自分で組み立てる必要があるので少し面倒です。

```ts
  let allData = "";
  const answer = AI.ask("Suggest 5 jazz songs");
  // Listen to "data" event to stream the answer
  answer.on("data", async (data) => {
    allData += data;
  })
```
:::

## 作ったもの

特長
- 選択したテキストを和訳
- 選択したテキストの言語を検出して保持
- 返信文の入力フォームを表示
- 翻訳トーン設定可能
- 返信元の文章のコンテキストを考慮しつつ、入力された返信文を抽出した言語で翻訳
- 翻訳文を和訳
- 翻訳文をクリップボードに保存

## なぜ作った？

以前紹介したRaycastのカスタムAIコマンドや、翻訳系の拡張機能を使って、いくつかのステップを踏めばもちろん同じようなことは実現できます。

1. 対象メッセージを選択して和訳コマンドを実行
2. 和訳結果をもとに返信文（日本語）を作成
3. 返信文を選択して英訳するコマンドを実行
4. 結果をコピーして返信

ただ、複数のコマンドを使うので若干面倒です。また、返信対象のメッセージのコンテキストは、返信文の英訳時に保持していないので、微妙に食い違った返信文を生成してしまう可能性もあります。

さらに、元の文章が英語以外の場合は、英訳コマンドではなく他のコマンドまたは通常のAI Chatで翻訳する必要があります。

それらが面倒なので、Raycast AI APIを使って、これらのステップを一括で実行できる前述のコマンドを作りました。
